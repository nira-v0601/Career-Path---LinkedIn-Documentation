## Shells Covered

### Bash
- Free, open-source replacement for the Bourne Shell,
  under the **GNU project**
- Includes more features than `sh` — command history,
  auto-completion, etc.

### GNU
A free open-source software, mass-collaboration project
announced to provide computer users freedom and control
in their use of computers.

### zsh
An extensive modern upgrade of `sh` — used in **macOS**
and Arch Linux derivatives like **Manjaro**.

## Commands Covered

| Command | What it Does |
|---------|-------------|
| `nano` | Used to see and edit a file |
| `ls -a` | Lists all files and directories, including hidden ones |
| `man` | Displays built-in reference manual (man pages) for terminal commands, system calls, and configuration files — marks the beginning of the Input/Output chapter |

---

## Flags
A **flag** is a modifier passed to a CLI tool to change its
behavior or enable specific features.

**Examples:**
- `ls -l` → lists files with their permission info
- `ls -a` → lists files, including hidden ones
