## Context
Linux operations happen mostly through the terminal —
understanding the file system inside it opens the door
to learning new commands.

As a lifelong Windows user (GUI + mouse/keyboard interaction),
working with files/directories through CLI-based commands
was a first-time experience.

---

## Commands Covered

| Command | What it Does |
|---------|-------------|
| `head` | Prints first n lines of a file's content |
| `tail` | Prints last n lines of a file's content |
| `touch` | Creates an empty file |
| `mkdir` | Creates a new directory (make directory) |
| `rm` | Removes a file/directory |
| `cp` | Copies a file/directory from one path to another |
| `~` | Shell expansion shortcut representing the current user's home directory (absolute path) |
| `grep` | Searches for a specific word/sentence within a file/directory |

---

## About Home Directory
User's individual personal space for storing personal data.
`~` is used to indicate the user's absolute home path.

---

## Honest Reflection

Learning these commands was fun and created excitement
for upcoming topics. Also identified a gap:
**lack of file path awareness** — encountered errors while
running commands in different paths.

**Action taken:** Practicing file paths & commands deliberately
to strengthen path understanding.

**Reflective question posed to audience:**
*"Are you also the one who got stuck sometimes due to
improper file path you are working with?"*
