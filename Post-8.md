## Topic Covered: git diff

**Purpose:**
Used to review changes before saving or sharing code.

**Why it's useful:**
- Helps carefully check changes before staging and committing
- Allows checking for typing errors and accidental edits
- Enables comparing local files with remote files

---

## Commands Learned

| Command | What it Does |
|---------|-------------|
| `git diff` | Reviews un-staged changes |
| `git diff --staged` | Reviews staged changes |
| `git diff -w` | Ignores whitespace and fetches the actual difference |
| `git diff --no-index <file1> <file2>` | Reviews differences between one or more standalone files |
| `git diff <hash1> <hash2>` | Compares differences between two commit hashes |
| `git diff --word-diff` | Shows word-to-word level differences |
| `git diff --stat` | Gives a line-to-line summary of changes |
