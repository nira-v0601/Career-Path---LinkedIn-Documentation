## Core Concept: GUI vs CLI

| Windows | Linux |
|---------|-------|
| Mostly operates through GUI (Graphical User Interface) | Mostly operates through CLI (Command Line Interface) |
| Does not allow system-level authorities | Allows system-level usage and permissions |
| Limited terminal dependency | Nearly all tasks — installing apps, editing files, running programs — happen through the terminal |

## Topics Covered This Week

- GUI & CLI fundamentals
- `echo "Hello World"` — first Linux command
- `whoami` — printing the current user's username
- `pwd` — Print Working Directory
- `history` — displays previously used terminal commands
- `clear` — clears the current terminal window
- `ls` — lists files and directories inside the current path
- `cd` — Change Directory

- Directory & File concepts
- File Path, Types, and Syntax differences across OS
