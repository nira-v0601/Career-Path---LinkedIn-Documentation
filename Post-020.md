## Commands Covered (1st Week of September)

### ✓ Date Command
- Prints date & time of the system in default Linux format
- Also learned custom formats using formatting tokens
- Practiced several formatting tokens for date, time, timezone,
  preformed shortcuts, and formatting modifiers

### ✓ List Command
- Previously known: `ls`, `ls -l`
- Learned additional extended flags this time
- Flags for sorting data by time, reverse time, and human-readable format

### ✓ Less Command
Used to find text top-to-bottom or vice versa.

### ✓ More Command
Used to read file content page-by-page inside the terminal.

### ✓ Visual Command
Used to create a new empty file and edit it in visual editor
(`insert` → `esc` → `:wq`)

### ✓ Sort Command
- Used to sort file contents in normal and reverse format
- Using `| uniq` for sorting in unique format —
  clears duplicate data
