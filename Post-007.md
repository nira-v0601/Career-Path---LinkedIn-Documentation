## Topic Covered: git stash

**Purpose:**
Temporarily save uncommitted changes in the working directory,
allowing a person to switch tasks/branches without losing
previous work.

**Simple Scenario:**
- Working on a file → suddenly need to switch to another file
- Don't want to commit (current changes still pending/incomplete)
- Use `git stash` → safely save current work without affecting
  other files → switch and start working on another file safely

---

## Commands Learned

| Command | What it Does |
|---------|-------------|
| `git stash` | Saves tracked file changes |
| `git stash -u` | Saves untracked files as well |
| `git stash list` | Displays list of all stashed entries |
| `git stash pop` | Restores latest stashed changes into working directory (no backup kept) |
| `git stash apply` | Same as pop, but keeps a backup of the stash |
| `git stash show` | Displays modified files with details |
| `git stash drop` | Deletes the latest stashed entry |
| `git stash clear` | Deletes all stashed entries at once ⚠️ Danger Zone |
